# GhostOptimizer

Strona i darmowe pobieranie: https://ghostoptimizer.pl

Najnowszy instalator Windows: [GhostOptimizer 1.6.1](https://ghostoptimizer.pl/downloads/GhostOptimizer-1.6.1-Setup.exe).

Jeden EXE obsługuje Free bez klucza oraz Pro po aktywacji. Sprzedaż Pro za 30 zł / 30 dni jest w przygotowaniu.

`version.json` informuje starsze wersje programu o bieżącym instalatorze. Nowe wersje korzystają z https://ghostoptimizer.pl/version.json.

Źródła programu są przechowywane w osobnym prywatnym repozytorium. Nie ma ich w tym repozytorium wydań.
